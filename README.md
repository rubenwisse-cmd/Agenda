# Screenshot naar Agenda

Zet een screenshot met datums in de app. De app leest de tekst (OCR, gebeurt op je eigen apparaat), vindt de datums en tijden en maakt er afspraken van die je in je agenda zet.

## Gebruik
1. Open `index.html` in je browser (of via GitHub Pages, zie hieronder).
2. Sleep een screenshot erin, tik om er een te kiezen, of plak er een met Ctrl/⌘+V.
3. Controleer de gevonden afspraken. Je kunt de titel, datum en tijd aanpassen.
4. Tik op **In agenda zetten (.ics)**:
   - **iPhone/Mac:** Agenda opent en je tikt op "Voeg alles toe".
   - **Android/Outlook/Windows:** open het gedownloade `afspraken.ics`, of gebruik per afspraak de link **Google Agenda**.

Herkent de app iets: "17-12-2026", "17/12", "ma 8 dec", "10 december 2026", "December 10, 2026", "2026-12-10", tijden zoals "14:00", "14.15", "19:30 - 21:00", "9u", "3pm".
Zonder jaartal kiest de app het eerstvolgende jaar waarin de datum valt.

## Op je telefoon zetten
Zet GitHub Pages aan (Settings → Pages → branch kiezen). Open dan de link op je telefoon en kies "Zet op beginscherm".
